# Code of Conduct

AmbaGrid is for people building useful energy infrastructure together. We want this project to be direct, technical, and welcoming.

## Our Standards

Good behavior includes:

- being respectful when you disagree
- giving clear technical feedback
- assuming good intent, but correcting harm when it happens
- helping new contributors understand the project
- keeping discussions focused on the work
- making space for people from different countries, backgrounds, and experience levels

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- racist, sexist, or degrading language
- sexual attention or comments in project spaces
- publishing someone's private information without consent
- repeated disruption of technical discussions
- using the project to intimidate, exclude, or shame people

## Project Spaces

This code of conduct applies in all AmbaGrid spaces:

- issues
- pull requests
- discussions
- chat rooms
- community calls
- conferences or events where someone represents the project

It also applies when behavior outside project spaces directly affects the safety or participation of the community.

## Enforcement

Maintainers may take action when this code is violated. Actions can include:

- a private warning
- editing or removing comments
- closing issues or pull requests
- temporary loss of participation privileges
- permanent removal from project spaces

Maintainers should explain enforcement decisions when it is safe and appropriate to do so.

## Reporting

If you see or experience unacceptable behavior, report it to the maintainers.

Until a dedicated security and conduct address is published, open a short private request with a maintainer and avoid posting sensitive details in a public issue.

Reports should include:

- what happened
- where it happened
- who was involved
- links or screenshots if available
- whether there is any immediate safety concern

Maintainers will handle reports as privately as possible.

## Scope of Technical Debate

Direct technical disagreement is allowed. Strong review is allowed. Saying "this design will drop messages under load" is not harassment.

The line is personal attack. Critique the code, design, docs, and tradeoffs. Do not attack the person.
